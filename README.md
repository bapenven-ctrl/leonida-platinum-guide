Leonida Platinum is a trophy guide and tracker for Grand Theft Auto VI on PlayStation 5. It covers all 55 official trophies with a full guide for each one, written for this entry and citing named sources; a six-stage roadmap to the platinum; conservative missable flags drawn only from the official descriptions (four trophies); and a working tracker with a searchable, filterable checklist, tracked counters, a spoiler shield for story trophies, and progress saved in the browser with JSON export and import. It runs fully offline as plain static files — no build step, no network.
## Run it
```sh
node serve.ts
```
then open http://localhost:8080
